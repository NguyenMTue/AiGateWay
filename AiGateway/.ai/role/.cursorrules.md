# AiGateway - Core AI Directives

## Technology Stack
- Language: C# 12, .NET 10
- Framework: ASP.NET Core Minimal APIs (Strictly NO Controllers)
- Architecture: Clean Architecture (Domain, Application, Infrastructure, WebApi)
- Database: PostgreSQL with Entity Framework Core 10
- Pattern: CQRS using MediatR

## Coding Standards
1. Use `record` types for DTOs, Commands, and Queries.
2. All asynchronous methods must end with `Async` suffix and accept a `CancellationToken ct`.
3. Use Dependency Injection via Primary Constructors (C# 12 feature).
4. For AI integrations, use `Polly v8` for Resilience Pipelines (Retry, Timeout, Fallback).

## Validation & Responses
1. Use `FluentValidation` injected into the MediatR pipeline.
2. All API responses must follow a standard wrapper: 
   `public record ApiResponse<T>(bool Success, T? Data, string? Error);`

## Structured Output (Crucial for AI Gateway)
When interacting with OpenAI/Gemini SDKs, always configure the LLM to return strict JSON format. Parse the JSON safely before returning to the Minimal API endpoint.
