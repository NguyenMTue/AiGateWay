Slide 01 • Giới thiệu Đề tài

Cổng Kết Nối API AI Trung Gian Dành Cho Game (AI Gateway)

Giải pháp cổng kết nối bảo mật, định tuyến thông minh, quản lý hạn ngạch & cảnh báo thời gian thực xây dựng trên **.NET 10 ASP.NET Core Minimal APIs**.

1. Lộ API Key Bí Mật

API Keys thật (OpenAI/Gemini) nhúng trong file binary (.apk, .exe) dễ bị decompile và đánh cắp.

2. Vỡ Ngân Sách ($ USD)

3. Gián Đoạn Trải Nghiệm NPC

Khi 1 Provider gặp lỗi 429/5xx, hội thoại NPC bị khựng hoặc crash nếu không có Fallback tự động.

4. Bài Toán Latency vs Cost

Hội thoại NPC cần phản hồi <500ms giá rẻ, trong khi cốt truyện chính cần mô hình suy luận sâu.

Slide 03 • Bảo mật & Quản lý Ngân sách

Mã Hóa AES-256 & Quản Lý Khóa Ảo (Virtual Keys)

Zero API Key Leakage

Game Client chỉ nắm Virtual Keys (`gw-live-...`). Toàn bộ API Keys gốc của OpenAI/Gemini được mã hóa **AES-256** an toàn trong cơ sở dữ liệu.

Phân Quyền Model Whitelisting

Phân quyền danh sách model được phép gọi (`AllowedModelAliases`). Khóa NPC chỉ được gọi model nhẹ, nếu cố gọi model cao cấp sẽ bị trả lỗi `403 Forbidden` ngay lập tức.

// Virtual Key Security Spec
Raw Key : gw-live-devtestkey1234567890abcdef
Hash SHA256: 8f9b...a12f
Max Budget : $100.00 USD
Limits : 60 RPM | 100,000 TPM
Allowed : ["gpt-4o-mini", "gemini-1.5-flash"]
LỜI THOẠI BÁO CÁO (SAY):

"Bảo mật là điểm sáng then chốt. Game Client không hề giữ API Key gốc. Client chỉ dùng Khóa ảo Virtual Key dạng `gw-live-...`. Toàn bộ Key thật được mã hóa AES-256. Đặc biệt, hệ thống phân quyền Model Whitelisting cho phép cài đặt Khóa NPC chỉ được gọi mô hình gpt-4o-mini. Nếu hacker cố tình dùng Key NPC để gọi gpt-4o nhằm làm tăng chi phí, Gateway sẽ lập tức chặn đứng với lỗi 403 Forbidden!"

Slide 05 • Hiệu năng & Khả năng Chịu lỗi

Semantic Response Cache & Polly Circuit Breaker

Semantic Response Caching

Tự động chuẩn hóa câu thoại prompt ➔ Tạo SHA-256 Semantic Key `semcache:{model}:{hash}` truy vấn Redis.

➔ Độ trễ (Latency) : < 2ms
➔ Chi phí (Cost) : $0.00 USD
➔ Tokens tiêu tốn : 0 Prompt / 0 Completion

Polly Circuit Breaker (Auto Failover)

Tự động ngắt mạch (chuyển sang trạng thái `OPEN` trong 60s) khi 1 Provider gặp 3 lỗi 5xx liên tiếp.

➔ Độ trễ ngắt mạch: 0ms (Chuyển mạch tức thì)
➔ Hành động xử lý : Tự động chuyển Fallback Model
➔ Tự phục hồi : Thử nghiệm Half-Open sau 60s
LỜI THOẠI BÁO CÁO (SAY):

"Để đảm bảo độ trễ siêu nhanh và chống sập trải nghiệm game, AI Gateway trang bị 2 cơ chế quan trọng: Đầu tiên là Semantic Response Cache. Với các câu hỏi lặp lại của người chơi đối với NPC, hệ thống đọc phản hồi sẵn từ Redis với độ trễ dưới 2ms và chi phí bằng 0$. Thứ hai là cơ chế Polly Circuit Breaker. Khi một Provider sập lỗi 5xx liên tiếp 3 lần, cầu chì lập tức ngắt mạch trong 0ms để chuyển sang mô hình dự phòng Fallback Model mà người chơi không hề nhận ra sự cố."
