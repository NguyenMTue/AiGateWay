Cổng Kết nối API AI Trung gian dành cho Game

Giải pháp cổng kết nối bảo mật, định tuyến thông minh, quản lý hạn ngạch & cảnh báo thời gian thực xây dựng trên **.NET 10 ASP.NET Core Minimal APIs**.

1. Lộ API Key bí mật

API Keys của OpenAI/Gemini nhúng trong file binary (.apk, .exe) dễ bị decompile và đánh cắp.

2. Cháy ngân sách ($ USD)

Sự cố vỡ trận chi phí do người chơi spam hoặc do bug lặp request liên tục từ Game Client.

3. Gián đoạn Trải nghiệm NPC

Khi 1 Provider gặp lỗi 429/5xx, cuộc thoại NPC bị khựng hoặc crash nếu không có Fallback.

4. Bài toán Latency vs Cost

Hội thoại NPC cần phản hồi <500ms với giá rẻ, trong khi cốt truyện chính cần mô hình suy luận sâu.

Slide 03 • Bảo mật & Phân quyền

Mã hóa AES-256 & Virtual Key Governance

Zero API Key Leakage

Client chỉ giữ Virtual Keys (`gw-live-...`) hoặc JWT Bearer Token. Toàn bộ API Keys thật của OpenAI/Gemini được mã hóa **AES-256** trong PostgreSQL.

Model Whitelisting per Key

Phân quyền danh sách mô hình được phép truy cập (`AllowedModelAliases`). Key NPC thường chỉ được gọi `gpt-4o-mini`, trả về `403 Forbidden` nếu cố gọi model khác.

// Virtual Key Security Spec
Raw Key : gw-live-devtestkey1234567890abcdef
Hash SHA256: 8f9b...a12f
Max Budget : $100.00 USD
Limits : 60 RPM | 100,000 TPM
Allowed : ["gpt-4o-mini", "gemini-1.5-flash"]
LỜI THOẠI PHÁT BIỂU (SAY):

"Bảo mật là điểm sáng đầu tiên. Game Client không lưu API Key thật. Client chỉ dùng Virtual Key hoặc JWT Token ngắn hạn. Key thật được mã hóa AES-256. Hệ thống phân quyền Model Whitelisting - ví dụ Key NPC chỉ được gọi gpt-4o-mini, cố gọi gpt-4o sẽ bị chặn 403 Forbidden."

Slide 05 • Hiệu năng & Khả năng Chịu lỗi

Semantic Response Cache & Polly Circuit Breaker

Semantic Response Caching

Tự động chuẩn hóa câu thoại prompt (lowercase, xóa dấu câu) ➔ Tạo SHA-256 Semantic Key `semcache:{model}:{hash}`.

➔ Latency: < 2ms
➔ Cost : $0.00 USD
➔ Tokens : 0 Prompt / 0 Completion

Polly Circuit Breaker (Auto Failover)

Tự động ngắt mạch (chuyển sang `OPEN` trong 60s) khi 1 Provider gặp 3 lỗi 5xx hoặc 429 liên tiếp.

➔ Bypass Overhead : 0ms (Ngay lập tức)
➔ Action Taken : Gọi Fallback Model
➔ Recovery Mode : Half-Open Trial Request
LỜI THOẠI PHÁT BIỂU (SAY):

"Bài toán tối ưu chi phí và chống sập: Với các câu hỏi lặp lại của NPC, Semantic Cache kiểm tra Redis và trả về phản hồi tức thì dưới 2ms, $0 cost. Khi Provider sập lỗi 5xx 3 lần liên tiếp, Polly Circuit Breaker chuyển mạch sang OPEN trong 0ms để gọi Fallback Model ngay trong cùng request HTTP."
